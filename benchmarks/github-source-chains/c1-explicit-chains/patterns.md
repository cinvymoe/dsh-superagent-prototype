# Reusable patterns

1. **Schema 收敛 + 读取归一化 + 严格保存**：面向“删除旧配置形状”时，让 `schema` 只描述当前形状，把旧形状转换放在一个只读的 `normalize` 步骤，并在读取入口（registry/服务解析）应用；保存路径不应用，保证存储向前迁移。
2. **“存在即显式”语义**：判断是否回退旧字段时看键是否存在，而不是看数组是否为空。`chains: []` 表示用户显式清空，不能被旧字段填补。
3. **旧形状读取端到端测试**：在存储层直接写入旧形状，断言面板 GET 显示归一化结果、PUT 一次后存储只含新形状；比只测 normalize 函数更能锁定集成行为。
4. **真实面板 Before/After 共享状态**：两个隔离 profile 共享同一 SQLite 快照，分别用基线与改动构建启动，同一场景/视口/主题截图；改动侧要展示读取旧数据的归一化效果。
5. **环境敏感测试的验收命令**：本仓库全量门用 `env -u GIT_CONFIG_GLOBAL LC_ALL=C pnpm check`，并在报告里说明基线同样失败，避免把环境问题当成本次回归。
