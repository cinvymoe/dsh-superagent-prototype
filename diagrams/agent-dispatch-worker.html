DSH Superagent · Agent Topology

一个调度 Agent，多个 Worker Agent

Dispatcher（Router）只做研判、路由与对外沟通；每个 Ticket 派生一个 Worker Session。
两者不直接对话，派工、回报和提问都经过 Engine 持久化。

01 / Dispatcher Agent

只做研判、路由与沟通

  • 角色 orchestrator，preset dsh-superagent-router
  • 模型取 settings.eval.model
  • 14 个 orchestrator_* 工具；accept / attach / stop / ignore
  • 不写代码；shell 与 job 等待上限 5 秒
  • 只转达 Worker 的结构化问题，不替 Worker 做技术决定

02 / Worker Agents

一个 Ticket 一个持久 Session

  • session id worker-<ticketId>，跨 turn 持久
  • 模型取 settings.executor.model
  • 6 个 orchestrator_* 工具 + 完整工作工具
  • 独立目录；prepare 只在首次派工前跑一次
  • maxWorkers 默认 3（1–16），另加 1 个人工插槽

03 / Engine

两者之间的唯一中转与账本

  • Intake / Eval / Ticket / Effects 四段式
  • SQLite 持久化；Router 与 Worker 都不直接改状态
  • launch 派工、relay 转报告/提问、reply 回写来源
  • reportRelay 把 Worker 的 attention 转给 Router
  • 已订阅 Thread 的人消息绕过 Router，由 Engine 直达 Worker
