DSH Superagent · 002 Authorization

一条 Trigger，只有两种去向

凡是订阅命中的 Thread，消息先扇出成上下文（不产生授权）；只有没被 Ticket 拥有的消息才进 Gate 与 Eval。Gate 给三档强度，accept mode 决定推断档能不能变成工单，Decision 只有 accept 会新建授权。

Strength · 三档

谁的话算数

  • explicit：名单上的人 @ 智能体，或在自己 Ticket 的 Thread 上跟帖
  • inferred：名单外的人跟帖、准入表给的推断格、名单上的 bot
  • not admitted：其他 bot、被准入表忽略的内容、off 模式下的推断档

Accept mode

推断档能不能变工单

  • off：推断档根本不成为候选
  • observe（默认）：判定会被记录为「would accept」，但不接单
  • auto：命中至少一条启用规则才接单
  • 显式请求在三种模式下都有效

Policy version

改规则的代价

  • 规则、accept mode 与各 Source 部分共同构成版本
  • 版本变化丢弃进行中的 Eval，并把它们的 Trigger 重新排队
  • 受影响的活动 Ticket 收到 policy-changed Input，但授权不立即撤销
