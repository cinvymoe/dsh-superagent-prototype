提示词是拼出来的，不是写出来的

团队写的是“话”，不是设置：团队段覆盖同名内置段，内置段有可改的默认文本，技能按 Source 注入，最后由角色决定段序与实现授权。每一份拼好的文本都留一个版本，所以“默认值变了”能被单独标出来。

Words, not settings

团队写的是文本

  • 行为差异用一段话描述，不新增开关
  • 内置段是默认文本，团队可以整段替换
  • 固定通知（比如重启恢复说明）不在可改范围

Precedence

谁覆盖谁

  • 团队段 > 同名内置段 > 代码里的默认文本
  • 技能的注入看角色与 Source kind
  • 角色的段序由代码固定，团队改不了顺序

Versions

改默认值怎么不破坏团队文本

  • 每次保存生成一个 prompt 版本，历史可对比
  • 升级改动被覆盖的默认段，标 Default updated
  • 保留我的文本 / 用新默认，二选一；旧默认没记录时直接和团队文本比
