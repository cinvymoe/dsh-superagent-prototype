DSH Superagent · Architecture

Router 决策 · Worker 执行

主 Session 只做研判与路由；每个 Ticket 派生一个持久 Worker Session；Engine 是唯一状态写入者。候选、决策、派工、回报与回写都在同一个闭环里。

01 / Router

决策面：只研判，不写代码

  • 角色 orchestrator，preset dsh-superagent-router
  • 模型取 settings.eval.model
  • 14 个 orchestrator_* 工具，读上下文 + 路由
  • 四类决策：accept / attach / stop / ignore
  • shell 与 job 等待上限 5 秒，禁止 sleep 轮询

02 / Worker

执行面：一个 Ticket 一个 Session

  • session id worker-<ticketId>，跨 turn 持久
  • 模型取 settings.executor.model
  • 6 个 orchestrator_* 工具 + 完整工作工具
  • 独立工作目录；prepare 只在首次派工前跑一次
  • maxWorkers 默认 3（1–16），另加 1 个人工插槽

03 / Engine

唯一写入者：所有状态在这里落账

  • Intake / Eval / Ticket / Effects 四段式
  • SQLite 持久化；主 Session 与 Worker 都不直接改状态
  • effects：assessment · launch · delivery · relay · reply
  • reportRelay 把 Worker 报告转回 Router
  • 已订阅 Thread 的人消息可绕过 Router 直达 Worker
