DSH Superagent · 007 Architecture · Persistence

没有外键，只有生成列和一列 JSON

一个 SQLite 文件，只有 Store 打开。表结构刻意薄：聚合体放在 value 这一列 JSON 里，真正要用索引的字段才提成生成列 —— 生成列 active / open / subscribed 就是这个系统的工作集。

Why one JSON column

聚合体整体读写

Engine 的命令总是整份读写一个聚合体，所以 value 存整份快照，事务比拆表简单。

  • 只有需要跨行过滤的字段才提成真实列
  • 生成列由 JSON 计算出来，定义变了就重建
  • 每张表只有一个写者；读走 storeRead

Working set

索引只覆盖“有活”的行

  • thread.active：有排队 Trigger 或正在评估
  • ticket.open / ticket.active：未结束 / 有未投递 Input 或运行中的 Assignment
  • thread.subscribed：带来源，用于按 Source 找线程

Growth

现在什么都不删

  • trigger、disposition、decision、已结束的 Ticket 都会一直增长
  • 升级前备份整个 stateDir；schema 只增不减
  • 队列与收据在下一张图：effect / outbox / disposition / kv
