DSH Superagent · 003 Execution · Ticket stages

一个 Ticket 的阶段，就是它在等谁

Ticket 不跟随 Session 的状态：它由「还在等什么」决定阶段。工作、等人、空闲、结束；人一旦说话，受阻的 Ticket 立刻回到工作。Assignment 与它平行，一个 Ticket 可以先后有多个。

Reading the rail

先看它在等谁

阶段按表格从上往下取第一条命中：投递失败 → Attention → ready → blocked/failed → 无 Assignment → waiting → 其余。

  • person/*：没有人的输入就动不了
  • working/queued：有活但没 slot
  • idle：这一轮干完了，没有悬着的问题

Assignment

与 Ticket 平行的第二条时间线

  • pending → running → ended，与 Ticket 状态各自独立
  • Retry 结束当前 Assignment，在同一个 Session、目录、分支、PR 上起新的
  • 重启后 running 的 Assignment 以 “host restarted” 结束，新 Assignment 带恢复提示，最旧优先

Ending

四种结束方式

  • 没有 PR 的 ready：completed
  • PR 全部关闭：按最后一次关闭的结果
  • dropped：无需处理，不留言
  • 人 stop：撤销 Mandate，永久结束
