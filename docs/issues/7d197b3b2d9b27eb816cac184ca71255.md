## 验收标准（冻结版）

- `POST local/issues` 接受图片数组（PNG/JPEG/WebP/GIF，每张 ≤5 MiB，最多 4 张），与需求同一次请求创建；任一张不合法则整单拒绝、不创建需求，并返回可本地化的错误。
- 图片落盘到 `<stateDir>/local-images/<issueId>/`，需求记录含每张图的 id、原名、媒体类型、字节数；`GET local/issues/:id` 返回这些元数据。
- `GET local/issues/:id/images/:imageId` 以存储的媒体类型返回原始字节（`cache-control: no-store`）；未知 id 404；不符合 same-origin 的请求 403。
- 需求触发文本包含每张图片的绝对路径，测试证明这些路径存在且是有效图片。
- 只有创建需求的路由允许更大的请求体（容纳图片），其他管理路由保持 128 KB 上限。
- `pnpm check` 通过，测试覆盖接受、拒绝（类型/大小/数量）、读取与超限请求。
