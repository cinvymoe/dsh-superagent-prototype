C1 已删除旧版单链路（仓库链路成为唯一配置）；C2 让每个本地项目拥有并隔离自己的链路。本 slice 承接「每个项目独立」在面板上的完整使用路径：**同一个独立表单既能创建项目，也能编辑当前项目；编辑或创建只提交当前项目，另一个项目的两条仓库展示与链路保持不变。**

## 现状与问题

- 本切片开始时 `main`（`afab266e`）的项目只有单一 `repository`，独立新建页只有「执行仓库（owner/name）」一个字段，也没有编辑项目的入口，`PUT local/projects/:id` 不存在。
- C2（PR #13）已加入项目链路：`POST`/`PUT local/projects`、创建页的接收 Issue 仓库与执行代码仓库、Discuss 页头与项目菜单的 `intake → code` 展示，以及服务端「只改本项目链路」的原子性。
- 缺的是面板上的编辑路径：已有项目无法从界面打开预填表单并保存；也没有面板级回归证明「编辑一个项目后，另一个项目的两条仓库展示与其链路不变」。

## 验收标准（冻结版）

以下五条逐字来自本工单 assignment 的 acceptance criteria，不改写、不增删。

- 新建项目页按上述四个字段渲染；提交 body 含 `name`、`intakeRepository`、`codeRepository` 与可选 `worktreeRoot`；服务端 400 时展示对应错误并留在当前页，不跳转。
- Discuss 页头或项目栏提供编辑入口；编辑表单预填当前项目值，保存 `PUT local/projects/:id` 后刷新并返回，另一个项目的两条仓库展示不变。
- Discuss 页头与项目菜单显示接收 Issue 的仓库和执行代码的仓库；空输入、非法仓库、相对 `worktreeRoot` 的既有校验文案保持。
- 项目 Tab 切换、溢出 More 菜单、独立新建页与取消/返回语义的既有测试仍通过；新增「编辑一个项目不影响另一个项目」的面板测试。
- `pnpm check` 全绿；PR 附同一视口、同一主题、同一语言的 Before/After 截图，baseline 为本切片开始时的 main head，after 为本分支 head。

## 实现方案

1. **路由（`src/client/route.ts`、`src/client/app.tsx`）**：Discuss 路由增加编辑态 `{ page: 'discuss', edit: <projectId> }`（与 issue 详情 `id`、新建 `create` 互斥）；`parseRoute` 归一化；`routeLabel` 对编辑页返回「编辑项目」，使返回按钮文案正确；`Pages` 在编辑态渲染项目表单。
2. **共用项目表单（`src/client/projects.tsx`）**：把现有 `NewProjectPage` 重构为 `ProjectFormPage`，创建与编辑共用四个字段与提交逻辑。编辑态从 `usePanelData().projects` 取当前项目并预填 `name`、`intakeRepository ?? codeRepository ?? repository`、`codeRepository ?? repository`、`worktreeRoot`；项目尚未加载时显示加载提示。创建提交 `POST local/projects`（空根目录省略字段）；编辑提交 `PUT local/projects/:id`（始终带 `worktreeRoot`，空字符串即清除）。成功时 `reloadProjects()`、`setProject(id)` 并 `navigate({ page: 'discuss' }, true)` 返回；失败时 `notify(errorText(failure))` 留在本页，两个输入不清空。
3. **编辑入口（`src/client/discuss.tsx`）**：Discuss 页头（`PageHead` 的 actions 区）为当前项目提供「编辑项目」按钮，打开该项目的编辑页；页头继续显示 `intake → code` 两条仓库。
4. **测试（`tests/panel-projects.spec.tsx`、`tests/panel-discuss.spec.tsx`）**：新增面板测试——两个项目时编辑其中一个，断言 PUT 路径与 body 只含当前项目、保存后页头显示新链路、切到另一个项目时其页头/项目菜单链路与原值逐字相同且没有额外 PUT；服务端 400（相对 worktreeRoot）时显示既有文案并停留在编辑页、不写回；清除 worktreeRoot 时 body 带空字符串。既有 Tab/More/新建/取消/返回测试保持通过。
5. **文档（`docs/005-panel.md`、`docs/007-architecture.md`、`tests/docs.spec.ts`）**：写清独立表单同时承担创建与编辑、编辑只提交当前项目并刷新返回、取消/返回不写入；`docs.spec.ts` 锁定这些语义。
