## 需求原文

> superagent 当前有几个执行的 Agent？需要在设置界面新增一个 Agent 的配置 页面 支持自定义当前 Agent 的工具和一些相关配置。

对齐方案确认的三类可配置角色：主 Session、对齐 Agent、执行器（子代理继承执行器工具，不单独配置）。
本切片只做**配置数据模型、校验与管理 API**，默认无配置时行为与现在完全一致，不改变任何运行中 Session 的行为。

## 验收标准（冻结版）

1. `SettingsSchema.parse({})` 得到空的 `agents` 三角色配置；旧设置（无 `agents`）照常解析，行为不变。
2. `GET settings` 返回 `blocks.agents` 的 value/revision，以及三角色工具目录（required/optional、预设名）。
3. `PUT settings/agents` 合法值保存成功、块 revision 递增并写入历史；关闭必需工具返回 400 与 `agentsRequiredTool`，未知工具返回 400 与 `agentsUnknownTool`，非 panel 来源返回 `panelOnlyAgents`，不可用模型返回 `modelUnavailable`。
4. 历史 diff 能显示每个角色的模型与工具变更（新增 `SettingsChangeCode`）。
5. 存储里出现目录中已不存在的工具名时仍能读取（运行期忽略），不会因升级失败。
6. `pnpm vitest run tests/agent-config.spec.ts tests/policy.spec.ts tests/settings.spec.ts tests/http.spec.ts tests/locales.spec.ts tests/docs.spec.ts` 与 `pnpm typecheck` 通过；PR 前 `pnpm check` 全绿。

## 任务拆解

- **C1（本次）** `agents` 设置块的数据模型、校验与管理 API：
  - `src/app/agent-tools.ts`（新）：三角色工具目录（`required` / `optional` / 预设名），把现有 `MAIN_TOOLS`、`COMPRESSION_TOOLS`、`WORK_TOOLS`、`ROUTER_PRESET`、`WORKER_PRESET` 收敛为唯一来源；`validateAgentTools` 抛出 `agentsRequiredTool` / `agentsUnknownTool`；`agentCatalog` 供设置视图读取。
  - `src/policy.ts`：`AGENT_ROLES`、`AgentRoleConfigSchema`（`model`、`disabledTools`）、`AgentsConfigSchema`、`SettingsSchema.agents`（缺省为空三角色）、`SettingsBlock` / `SettingsSave` 增加 `agents`。读取宽松：`disabledTools` 为有界字符串数组，不校验目录成员。
  - `src/app/settings.ts`：`agents` block 的 parse（目录校验）/ merge / panel-only guard（`panelOnlyAgents`）；按角色逐个校验模型覆盖（`modelUnavailable`）；`view()` 暴露 `agents` 块。
  - `src/app/views/settings.ts`：`blocks.agents`（value/revision）与 `agents.roles` 目录进入 `GET settings`；`src/app/api.ts` 类型随视图推导。
  - `src/app/settings-history.ts`：每角色模型/工具变更的新 `SettingsChangeCode`（`agentMainModel`、`agentAlignerModel`、`agentExecutorModel`、`agentMainTools`、`agentAlignerTools`、`agentExecutorTools`），旧快照缺 `agents` 时按空配置比较。
  - `src/app/http.ts`：`PUT settings/:block` 接受 `agents`；`src/app/tools/main.ts`、`src/app/resources.ts`：`agents` 块可读、工具保存被 panel-only 拒绝。
  - `src/core/errors.ts`、`src/client/locales.ts`：新错误码与中英文案、历史 change 文案。
  - `docs/006-deployment.md`、`docs/007-architecture.md`：新模块行、测试行、`agents` 块与保存来源说明。
  - 测试：`tests/agent-config.spec.ts`（新增，纯配置 + HTTP + 历史）、`tests/policy.spec.ts`、`tests/settings.spec.ts`、`tests/http.spec.ts`、`tests/locales.spec.ts`。
