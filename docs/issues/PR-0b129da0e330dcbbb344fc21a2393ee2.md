# PR · C1 retry · 工单 worktree 根目录解析与启动校验

This is by an automated agent, not a human.

## Outcome

`createProject` now treats an omitted, empty-string and whitespace-only `worktreeRoot` as unconfigured: no field is stored and no error is raised, while a relative path still fails with the existing `UserError('projectWorktreeRoot')` message.

## Context

Slice C1 (retry) of the confirmed Discuss alignment `q-94e6e32e`. C1's core — project `worktreeRoot` resolution (`project > executor.directory > <stateDir>/work`), per-Ticket directory/root persistence, pre-launch existence/directory/writability validation, failure without retry and recovery via retry or a human message — already landed on `main` in `2e79202 feat: support per-project worktree roots`. The retry alignment tightened one acceptance clause: whitespace-only values are now equivalent to unconfigured instead of being rejected. This PR implements that delta and locks it with tests.
