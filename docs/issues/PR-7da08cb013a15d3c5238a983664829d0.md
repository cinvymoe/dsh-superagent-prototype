# PR · C3 · 面板按项目创建/编辑两条仓库并展示隔离结果

## Outcome

The standalone project page is now both the creation form and the edit form. The Discuss page head has an **编辑项目** entry that opens the current project's form pre-filled with its name, intake repository, code repository and optional worktree root. Saving sends `PUT local/projects/:id`, reloads the projects and returns to Discuss; a refused save keeps the page and the typed values, Cancel and Back write nothing. Editing one project leaves the other project's two repositories unchanged in the page head, the More menu and the stored chain.
